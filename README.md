# HBM Consultants — Haris Bin Maqsood

Professional consultancy website for Haris Bin Maqsood, independent public procurement and technology governance advisor based in Karachi, Pakistan.

## Hosting
The site is a static HTML website. A GitHub Actions workflow deploys on changes to `main` once GitHub Pages is activated for this repository.

Enable GitHub Pages at: https://github.com/muhammadmohsinnisar/haris_bin_maqsood/settings/pages
Select **GitHub Actions** as the build/deployment source.

Default site URL: https://muhammadmohsinnisar.github.io/haris_bin_maqsood/

## Edit
Edit `index.html` in GitHub, then commit. GitHub Actions republishes the site. Email, WhatsApp and LinkedIn URLs are in the Contact section. You can add an approved photo later.

## Domain
A custom domain such as `hbm-consultants.com` requires separate purchase and DNS configuration. Don't set a CNAME before owning the domain.

Professional background is based on the supplied CV and clarified procurement responsibilities. Verify before public launch. No affiliation with or endorsement by government institutions is implied.
